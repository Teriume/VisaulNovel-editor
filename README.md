# Na-Na Visual Novel

## Сборка

```sh
cmake -S . -B build
cmake --build build -j2
```

Сборка создаёт две программы:

- `build/VisualNovelEditor` - редактор сцен, текста, переходов и ресурсов.
- `build/VisualNovelPlayer` - отдельная игра без ImGui.

## Запуск готовой новеллы

Проект сохраняется редактором в файл `.nana`. Запустить его отдельно:

```sh
./build/VisualNovelPlayer /path/to/novel.nana
```

В редакторе та же команда доступна через кнопку «Запустить отдельной игрой».

Файлы `.nana` хранят сценарий и относительные пути к ресурсам. Поэтому проект удобно переносить вместе с папкой `assets`. Файлы `.nanasave` хранят прогресс игрока, а `.bgpresets` - пресеты фонов.

## Почему не ImGui для игры

ImGui оставлен только для инструментов редактора: он быстрый и удобный для инспекторов. Игрок использует обычные SFML-элементы и не зависит от ImGui. В будущем редактор можно переписать на Qt, если понадобятся полноценные док-панели, undo/redo, дерево проекта и сложные диалоги. Для игрового интерфейса лучше оставить SFML или перейти на RmlUi, если понадобится HTML/CSS-подобная разметка.
